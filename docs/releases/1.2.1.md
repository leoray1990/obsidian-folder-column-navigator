# Folder Column Navigator 1.2.1

本版本相对 **1.2.0** 修复日历设置反复渲染和滚动跳底，优化每日笔记创建规则的编辑体验，并更新全新安装使用的默认配置。

## 问题修复

- 修复修改日历配置后页面跳到最底部的问题：设置刷新及积木编辑器重绘均保留滚动位置。
- 修复“创建每日笔记”区域每修改一次设置就多展示一份的问题：设置变更只刷新一次，自定义编辑器复用唯一容器，并清理重复容器。
- 关闭“启用每日笔记创建”后立即保存，并隐藏所有其余创建配置；重新开启可恢复编辑，保存失败时恢复原开关状态。启用开关不会顺带保存未确认的规则草稿。
- 修复部分默认值在加载配置时被硬编码回退逻辑覆盖的问题；未设置的配置读取新默认值，已有显式设置仍保持原值。

## 创建规则与设置布局优化

- 将“创建每日笔记”整个配置区域移到日历设置最底部，常规展示和日期匹配配置在前。
- 常用方案按“按年月”“平铺日期”“按年月周”排序，下拉默认选择“按年月”；“选择方案后仍可自由编辑”改为备注，不再是一个方案选项。
- 新增“应用方案”按钮，可重新应用当前下拉选项。打开设置不会自动用方案覆盖已有自定义规则。
- “按年月周”预置的周区间改为 `MM-DD-MM-DD`，不再重复年份，例如 `11-16-11-22`。既有已保存模板不自动改写。
- 日期组件库补充可直接添加的“周开始”“周结束”月日组合积木，格式可在 `MM-DD`、`M-D`、`MMDD` 中选择。
- 将预览日期放到完整路径预览上方，便于先选择测试日期，再核对生成路径。
- 目录组件库收敛为三类：“基础”“日期相关”“固定文字”。基础目录和目录分隔符 `/` 统一放入“基础”，不再单独显示“目录分隔符”分类。

## 默认配置调整

以下通用偏好更新为**新安装或缺省配置**的默认值，不强制覆盖已有用户设置：

| 配置 | 1.2.0 默认值 | 1.2.1 默认值 |
| --- | --- | --- |
| 一级目录布局 | 左侧目录列 | 顶部目录标签 |
| 顶部默认展示行数 | 2 | 8 |
| 长名称自动换行 | 关闭 | 开启 |
| 条目分割线 | 显示 | 隐藏 |
| 文件树名称左对齐 | 关闭 | 开启 |
| 文件夹笔记 | 关闭 | 开启 |
| 文件后缀名 | 显示 | 隐藏 |
| 深层目录纵向展开 | 关闭 | 开启（最大水平列数仍为 4） |
| 点击目录在当前列打开 | 关闭 | 开启 |
| 当前列打开起始列 | 第 2 列 | 第 3 列 |
| 文件夹图标 | 文件夹 | 箭头 |
| 文件图标 | 显示 | 不显示 |
| 文件列表底部日历 | 显示 | 不显示；独立日历仍可通过命令打开 |
| 按创建日期匹配 | 开启 | 关闭 |
| 按修改日期匹配 | 开启 | 关闭 |

仍默认使用简洁分格主题、当前操作列靠左定位、文件属性/文件名日期匹配。日记默认路径仍是 `日记/YYYY-MM-DD.md`，创建方案预置可以手动应用。

默认配置不包含任何个人仓库的自定义目录名单、隐藏目录、导航顺序、历史排序、目录列宽、限定查找目录或日期与笔记路径关联。已有 `data.json` 不会被整体替换。
