# Folder Column Navigator 1.3.2

相对 **1.3.1**，本次补齐插件中英文国际化。界面自动跟随 Obsidian 的语言设置，无需单独选择插件语言。

## 新增功能

### 自动跟随 Obsidian 界面语言

- Obsidian 使用中文语言时，插件显示简体中文；英文及暂未提供翻译的其他语言使用英文。
- 按 Obsidian 的正常流程重启或重载后应用语言切换。
- 设置分类、选项名称、说明、下拉选项、占位提示、命令、导航工具栏、右键菜单、选择与确认弹窗、Toast、错误提示和无障碍标签均接入统一翻译层。
- 本次覆盖 **465 条界面文案**，新增英文翻译目录与参数占位符校验；动态文件名和路径仅作为文字插入，不递归替换其中的模板内容。

### 英文日历与日记创建编辑器

- 日历星期、月份、年/月/周视图标题、导航按钮、匹配文件列表及创建入口支持英文。
- 中国大陆节假日名称提供英文显示，休/班标记对应 **Off / Work**；合并节日名称也可翻译。只改变显示，不改变放假、调休或工作日计算规则。
- 英文标记预留独立顶部空间，避免窄宽度下与日期圆点、匹配数量角标重叠。
- 日记创建的常用方案、日期来源、积木名称、编辑说明、路径校验、模板来源及创建确认弹窗支持英文。
- 英文新安装和显式应用预设时使用 `Daily` 作为建议基础目录；已有规则和实际目录不会随语言切换重命名。

### 英文外观与数量文案

- 插件设置和 Style Settings 的主题名称支持英文，保留中文标签；主题样式与已保存选择不变。
- 文件计数及常用操作提示区分英文单复数，例如 **1 file / 2 files**。

## 配置与数据保留

- 已有文件名、目录名、自定义显示名、属性名与值、分组值、隐藏规则、模板路径和已保存的创建规则保持原样。
- 默认识别的中文属性、文件夹笔记名称及中文日期格式继续有效，不因英文界面失去匹配能力。
- 节假日离线数据和联网更新缓存保持原始内容，只在显示时翻译已知节日名称；未知名称保留原文。
- 第三方插件附加菜单项和笔记内容由各自来源决定语言，不强制翻译或改写。
- 不新增网络请求、运行时依赖或插件语言配置。最低 Obsidian 版本仍为 **1.13.0**。

## 文档与验证

- README 增加中英文“界面语言”说明，解释语言切换流程及用户数据保留边界。
- 新增国际化回归测试并加入 Release CI，校验翻译覆盖、参数占位符、单复数、语言回退、设置键稳定性、菜单文案及未知节日名称回退。
- 每日笔记、模板、节假日、启动设置、大库日期索引与目录空白右键菜单的既有回归测试通过。
- 独立浏览器验证中英文日历、月/周切换、窄宽度、标记布局，以及十万条匹配结果的虚拟列表渲染。
- 在隔离 Obsidian 1.15.1 演示仓库中验证英文分类设置、右键菜单、日记积木编辑器和日历匹配列表；验证后恢复演示环境语言，未使用真实笔记内容。
- 用户已确认本次测试无问题；这些结果不等同于所有设备与主题组合均已验收。
