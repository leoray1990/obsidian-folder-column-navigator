# Folder Column Navigator 1.2.0

本次为相对 **1.1.3** 的完整功能更新，新增每日笔记创建、模板、积木规则编辑、多选批量操作和更灵活的多列导航，并修复大仓库启动、规则保存和预览稳定性问题。

## 新增功能

### 日历创建每日笔记

- 无匹配文件的日期支持点击创建；已有匹配文件时，使用 `Cmd + 点击`（Windows/Linux 为 `Ctrl + 点击`）创建新笔记。独立日历文件列表及匹配列表弹窗增加“创建每日笔记”入口。
- 创建前显示确认弹窗，预览日期、目录、文件名、类型和模板；文件名可修改，实时检测重名。确认后自动创建缺失目录并打开文件，不覆盖已有文件。
- 支持 Markdown、Canvas、Base 三种文件类型；默认选中日记日期，无模板 Markdown 写入 `date` 属性。
- 保存日历日期与新建文件的关联：过去日期、自定义名称、Canvas/Base 也能重新找到；文件改名/移动时更新关联，删除后清理。

### 积木式创建规则与正文模板

- 笔记目录与文件名支持点击添加积木、拖拽排序、左右移动、悬停删除；触屏可通过按钮操作。
- 组件分为日期相关、固定文字和目录分隔符。支持年/月/日/星期/周数、周开始/结束日期、固定文字、连接符、下划线、空格和 `/`。
- 新增固定在最左侧的“基础目录”积木，支持编辑及仓库目录补全；普通固定文字不再提示文件或目录，禁止非法字符和目录分隔符。日期来源和同类格式使用下拉选择，减少误配置。
- 提供平铺日期、按年月、按年月周预置方案，以及自由输入的高级模板。支持选择测试日期并实时预览完整路径；规则需显式保存后生效。
- Markdown 正文支持 Obsidian 模板变量 `{{title}}`、`{{date}}`、`{{time}}` 及日期/时间格式；日记 `date` 使用日历选中日，`time` 使用实际创建时间。
- 支持启用 Templater 后使用其原生模板创建流程；模板文件可搜索提示。模板缺失、插件未启用、执行失败或取消会明确提示，不降级为空白笔记。

### 多列导航与显示

- 新增“点击目录在当前列打开”：默认关闭，默认从第 2 列生效，可配置第 1–8 列。当前列内返回使用向上箭头，左方向键在当前列返回并定位刚离开的目录。
- 鼠标点击和 Enter 共用打开规则；打开当前列或新子列后自动聚焦第一个实际条目，不自动打开首个文件。
- 新增“打开目录后的横向定位”：当前操作列靠左（默认）、保留左侧 1 列、保留左侧 2 列、新展开列靠左、新展开列靠右、不自动滚动。左侧一级目录栏始终独立保留，键盘上下移动不触发下一列定位。
- 支持双击列进行横向可见性定位；普通点击不再额外触发原生焦点滚动。
- 新增条目分割线开关，可隐藏文件与目录之间的横线，保留列边界和分组标题。

### 多选、排序与分组

- 支持 `Shift + 单击` 连续范围选择、`Cmd/Ctrl + 单击` 增减选择，以及键盘扩展选择。
- 多选条目支持右键批量移动、删除、设置分组、修改属性，并展示执行结果；目录属性操作基于对应文件夹笔记。
- 同级文件或目录可拖拽调整顺序，自动切换为自定义排序，按目录保存顺序；也可拖到列空白区域移动到该目录。
- 文件/目录可拖入分组，或通过右键设置分组；普通分组更新首个有效分组并移除归档标记，拖入归档时添加归档标记、保留原分组信息。
- “其他”组固定排在普通分组之后、归档之前；文件夹笔记不因分组置顶而失去优先位置。文件夹右键新增“创建文件夹笔记”。

### 主题与悬浮预览

- 内置简洁分格（默认）、彩色、手帐主题，覆盖导航、文件树、分组、日历、按钮和插件菜单，并支持 Style Settings。
- 彩色主题提供彩虹、海盐、森野、晚霞配色；新增彩虹目录开关，关闭后移除目录渐变和装饰色条。插件主题设置在启动时优先恢复。
- 右键菜单与悬浮预览背景不透明度可分别设置，默认 70%，调整背景而不降低文字不透明度。
- 悬浮预览支持总开关，以及是否预览文件夹笔记；普通悬停使用箭头指针，拖拽能力保留。

## 问题修复

- **大仓库启动白屏/卡顿**：避免启动时逐文件刷新；文件和元数据事件合并刷新；设置页仅在可见时更新；读取一级目录不再遍历全库。
- **保存创建规则卡住**：改为持久化和轻量更新创建入口，不触发全局刷新、全库重新匹配或编辑器重建；保存失败恢复原规则。
- **同一天大量文件匹配缓慢**：按日期使用集合去重，避免二次复杂度；复用排序比较器。
- 修复点击文件后垂直滚动位置跳动，按目录恢复原列滚动位置；恢复焦点使用受控滚动。
- 修复点击文件后仍保留已打开兄弟目录的选中状态与右侧内容列。
- 修复鼠标点击、Enter 与当前列打开配置不一致，以及打开后没有聚焦首项的问题。
- 修复顶部标签默认行数多显示一行、隐藏/显示与高级隐藏规则冲突；一级目录与自定义一级目录由导航配置单独管理。
- 修复目录/文件点击造成工具栏图标闪动，复用未变化的导航和图标状态。
- 修复自定义显示名称被文件夹笔记 aliases 覆盖，以及文件夹展开/收起图标未区分的问题；日期详情去掉重复的“创建于/修改于”前缀。
- 修复文件夹笔记在置顶分组后面、右键缺少文件夹笔记创建入口的问题。
- 修复预览窗口在鼠标经过相邻条目时立即消失；进入预览后取消待切换/待关闭操作；返回同一文件复用现有窗口，避免空白窄窗闪烁。
- 修复默认主题启动后意外恢复为手帐主题、菜单背景过度透明、排序按钮间距不足和彩色标签装饰过重的问题。

## 兼容与使用提示

- 最低版本仍为 **Obsidian 1.13.0**，支持桌面与移动端。
- 新的当前列打开默认关闭；横向定位默认当前操作列靠左，旧版明确关闭自动滚动的选择会保留。
- 周区间从周一开始，与当前日历一致；高级模板的 `date` 指日历选中日，`today` 指创建当天。
- Canvas/Base 暂不应用 Markdown 正文模板；选用正文模板时，不强制插入额外 frontmatter。
- Templater 是可选依赖，不会被打包。其 `tp.date.now()` 保持原生日期语义，不自动改为日历选中日；模板脚本可能请求网络或执行文件操作，只选择可信模板。
- 日期与笔记的关联保存在当前仓库插件配置中，不会自动跨设备同步；匹配遵循隐藏规则，已创建笔记的显式日期关联可独立于普通目录/类型匹配条件。
