# Folder Column Navigator 1.3.1

相对 **1.3.0**，本次增加目录空白区域右键菜单，并完整覆盖一级目录导航和任意层级文件列。

## 新增功能

- 在左侧或顶部一级目录区域的空白处右键，打开仓库根目录菜单，可在根目录新建笔记、文件夹、白板或数据库。
- 在任意层级文件列的空白处、列标题或空目录提示处右键，打开该列对应目录的菜单，复用原有目录操作和可选第三方 `file-menu` 扩展项。
- 菜单继续支持已有的键盘移动、输入过滤和确认操作，无需先选中目录条目。

## 问题修复

- 补齐仅监听列表内容时遗漏的一级目录面板、列标题、内边距与列表外留白，第一列和后续子列使用一致的处理方式。
- 空白区域根据所属面板或文件列确定目标目录，不使用之前选中的文件或其他列目录。
- 文件、目录条目和分组的原有右键菜单保持不变；工具栏按钮、筛选控件和列宽分隔条不会被当成目录空白区域处理。
- 打开菜单时不主动水平或垂直滚动，也不展开或收回其他目录列。

## 验证与兼容

- 新增目录菜单事件回归测试，并加入 Release CI；覆盖左侧/顶部一级目录区域、第一列与多层子列、标题/内边距/空状态，以及条目和控件排除规则。
- 本地构建、现有每日笔记与日历回归测试通过。
- 在运行中的 Obsidian 插件界面检查了 8 个面板、列标题和列表区域，均正确匹配所属目录。
- 最低 Obsidian 版本仍为 **1.13.0**，没有新增依赖，不重置原有配置。
